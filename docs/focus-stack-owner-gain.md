# 流式画作 owner 增益

本功能只用于 FlatArtwork 流式合成。原先以不同来源的画面中位数归一化，容易把画作、墙面和金属反光的内容差异当作曝光差异。v53 同冻结二进制原生 A/B 表明，去掉 owner 校正能缩小兰亭相对用户参考的四区灰度差并改善底边，但顶部墙面过渡略差。

## 受限估计

在写入当前来源前，复用已有 base/candidate 分析图；candidate 先应用实际 write_tone，因此只估计残余曝光，避免重复校正。5×5邻域要求双方均有效、base owner一致、非饱和、纹理方差充分，亮度相关系数至少0.9。残余对数亮度比超过0.20则拒绝。

按候选owner、base owner和512输出像素空间格收集证据，每格最多32样本、全局最多65536格。至少8样本且覆盖格内两个象限，对数比MAD≤0.025才可用；同格不同base owner估计相差>0.05时整格拒绝。

增益使用单一亮度标量，不单独重估RGB白平衡；它只修正有依据的曝光残差，不能消除不同视角的金属反光或真实几何差异。

增益限制为1/1.08至1.08，分析格仅接收同owner且证据附近的增益，空间支持半径768输出像素并向单位增益衰减。无可靠证据的分析格使用单位增益；最终双线性采样会在owner/支持边界的一个分析像素内过渡（兰亭约16.5输出像素），幅度仍受相同上限约束。保留逐图tone和整图低频平滑，不再以不同内容的owner中位数补全证据空白。

诊断目录metadata.json和日志记录方法、样本量、候选/通过格、溢出数和限制。`RAW_EDITOR_SKIP_SOURCE_OWNER_CORRECTION`用于关闭对照；`RAW_EDITOR_LEGACY_SOURCE_OWNER_CORRECTION`用于旧算法对照。

## 验收

同45张兰亭JPEG、scale=1、冻结二进制、原生16位TIFF，参考图保持只读。核对输入摘要、来源Coverage/owner/alpha、取景坐标及文件写出合同。新增定向测试覆盖不相关纹理、证据分布、不同base冲突、幅度、空间边界、owner隔离及tone残差。

区域指标用于视觉复核，不能替代既有Quality Gate：顶部墙面/挂杆跨边差中位数相对v51增量不超过一个8位码值，底边跨边差下降，参考图四区概览MAE不增加。检查原生裁片中笔画、纹理和边缘，单独列出反光或局部几何不可比限制。区域诊断容差不是放宽Quality Gate阈值。

同冻结二进制重跑9张NEF冷/热，要求保持既有QG、TIFF摘要、RAW18/fusion6、默认512MiB/1GiB缓存及来源证据。

结果与项目状态以[总览](project-progress.md)为准。

## v54 实跑结果

45张原生取景的全部来源/文件合同通过；31,095样本中358个owner空间格通过，无容量溢出。相对旧算法，底边跨边差中位数由0.0710降至0.0225；顶部墙面增量约0.00183，小于预先记录的1/255区域诊断容差，挂杆未增加。参考四区MAE均下降。直接从最终16位TIFF抽取顶部与底框，复看原生1:1裁片后，本阶段区域检查通过。

同冻结二进制9张NEF冷/热均保持v28 TIFF摘要、QG pass/8ROI、RAW18/fusion6和默认缓存预算。完整库测试1047通过、0失败、42忽略。

本阶段收益主要来自拒绝不受同内容证据支持的owner中位数增益，残余增益本身很小。兰亭完整QG仍为`insufficient_evidence`，反光与来源内容差异仍可见；本阶段完成不代表整个N6.5完成。实跑使用已有显式取景开关，默认画布规则未更改。

用户后续明确否决v54的整图亮度、色调和拼接块。局部指标通过未建立整图视觉验收；v55/v56进一步确认并修复了整图平滑混合不同材质造成的主要亮度回退，见[整图亮度与色调](focus-stack-artwork-illumination.md)。
