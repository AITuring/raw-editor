# 画作整图亮度与色调

用户已否决v54整图观感：整体亮度、色调和拼接块与`DSC08854_FocusStack.jpg`差异明显。v54局部底边指标通过不能视为整图视觉通过。

当前默认像素保持v60；v62补齐原生质量证据，v63完成取景基线与CLI集成验收。保留来源重叠tone及有来源证据的owner残差增益，FlatArtwork整图材质归一化和匹配tone仍为显式实验。同45张原生QualityGate pass/8ROI、严格保护与CLI通过；同二进制9张NEF冷/热保持v28。主体未见明显矩形色块，整体接近参考但纸色仍略暖，真实反光保留。当前范围和限制以[总览](project-progress.md)及[v63摘要](benchmarks/lanting-v63-native-quality-acceptance.json)为准。

## 根因与对照

原整图平滑用16分析像素局部均值与640像素宽范围均值求RGB增益，允许0.70～1.40倍。宽范围均值混合了墙面、深色画作和亮挂杆，使真实材质差异参与曝光估计；单独去掉owner中位数校正不足以解决这个问题。

v55复用v54冻结二进制，只关闭整图平滑，45张、scale=1原生输出：相对只读参考的灰度概览MAE，墙面24.48→7.19、挂杆40.63→12.11、画作8.16→4.61、底框11.17→6.28。实际预览中墙面和挂杆恢复亮度，整体层次接近参考。单纯关闭仍可能保留同材质的曝光阶跃，因此继续验证受限平滑。

## v56实现

仅FlatArtwork流式路径使用新的亮度相似度约束滤波；其他路径保留原函数行为。

- 在最长边600的分析图中估计局部亮度，12个重叠亮度区间限制宽范围统计的来源，避免挂杆与深色画作混合。
- 每区间用三次线性复杂度盒滤波近似宽空间平滑，按支持归一化；空支持返回原亮度。
- 只施加亮度标量，不从整图宽均值重新求各RGB通道白平衡。
- 大幅宽/局部差异缺少曝光证据，平滑衰减作用；明亮材质的暗化限制渐变收紧到约1%。独立来源重叠支持的owner残差增益另行保留。

定向测试同时要求亮挂杆保真、同材质小曝光阶跃下降、RGB通道比不变，保留既有质量门禁和来源证据。

## 验收边界

检查整图观感、墙面/挂杆/画作/底框、原生裁片及参考灰度/色调分布；原有跨边指标只作诊断，不再凭这些局部指标宣称整图通过。金属反光在不同来源/视角间存在真实差异，不能把参考图片当作输出像素来源。

完整状态与实跑结果见[项目总览](project-progress.md)。

## v56结果

同45张scale=1，来源、Coverage/owner图、alpha与输出合同全部通过，参考未修改。相对用户否决的v54，墙面/挂杆/画作/底框参考灰度MAE由24.48/40.63/8.16/11.17降至5.42/12.31/4.92/7.63。整图及最终16位TIFF裁片复看确认整片压暗减轻，墙面与挂杆的色度误差也下降。

改善有边界：画作和底框色度误差略增，挂杆及底边的跨边差指标比v54略大；局部反光、来源内容和色差尚未解决。兰亭Quality Gate仍为insufficient_evidence，整体视觉不记为完整通过，不能再以几个局部指标收口。

完整库测试1048通过/0失败/42忽略。同冻结二进制9张NEF默认缓存冷/热全部断言通过，QG pass/8ROI、TIFF保持v28摘要、RAW18/fusion6，来源证据不变。

## 2026-11-11：兰亭作为优化保留的前提

用户要求兰亭完整成片可靠后，性能提升才有意义。不能把Rust测试、文件合同、局部MAE改善或来源计数通过写成兰亭整体通过。

v57在逐图写入处直接更换tone，改变了后续层读取的base，导致来源覆盖和取景坐标变化，拒绝。v58将修正移至最终几何/owner冻结之后，恢复全部来源/画布合同，但全边界诊断疑点增加、底框亮度误差增大且新裁切高光增加，仍拒绝。真实运行与摘要保留在[拒绝记录](benchmarks/lanting-v57-v58-rejected-tone-candidates.json)。

后续候选只在以下条件下修改原色调：5×5有效补丁内容一致；拟合与留出采样交错且互不重叠；每格至少12个拟合与12个留出样本；稳健离差通过；留出误差比原场至少下降20%。无证据或原场已正确时保留原场。新增修正限制在±0.04对数增益，仅在已验证区域附近传播。平坦补丁只支持光度估计，不能充当独立几何证据。

几何与owner完成后再读取冻结来源色调场，使用2048长边增益网格和0.75格的平滑衔接已有羽化；只平滑修正场，不模糊RGB细节。高亮保留余量，最终TIFF额外核对实际裁切像素统计。不增加来源解码。

全图边界审计覆盖108组可见来源对，并单列不可测点；v1采用整数粗配准，v2补充0.5预览像素细配准，两版均保留。统一阈值下分别比较新旧成片，局部对比度归一化避免把笔画清晰度差别直接当接缝。人工注入亮度阶跃和纯曝光/对比度对照用于校准审计；它仍不替代现有Quality Gate。

## 主体优先的默认路径与回归保护

用户进一步明确：优先消除画作主体色块，真实反光可以保留。底框视角反光不再作为本阶段应消除的对象。

v59的独立留出限制避免了错误修正，但其最终TIFF与v56完全相同，不能记作新的画质提升。纸面背景的独立审计随后表明：保留来源重叠tone、关闭整图材质归一化的对照更接近参考，且纸面相邻残差中位数/P95由2/4降至1/3个8位码值。因此v60默认不做FlatArtwork整图重归一化；原来源重叠tone及有证据的owner残差增益保留。匹配tone重放仅在`RAW_EDITOR_MATCHED_ARTWORK_TONE=1`下实验运行；材质归一化仅在`RAW_EDITOR_ENABLE_ARTWORK_ILLUMINATION=1`下实验运行，不因测试通过就进入默认。

纸面审计限定在参考图确定的画作区域，剔除深色笔墨和红印，再比较局部纸色与参考的残差。314组跨owner边界的P95为3，与1623组纸面内部比较相同；最大值均为7，唯一超过6码值诊断线的来源边界已单独抽取原生TIFF/参考裁片复看。这支持当前范围内未观察到突出的矩形色块，不是对每个像素或全部画质指标的证明；整体偏暖和参考局部纸色/阴影差异仍单列。

已新增`tests/acceptance/lanting-paper-baseline.json`与`tests/focus-stack-lanting-guard.mjs`，冻结同45张、取景TIFF摘要、来源Coverage/owner、alpha/位深、画布和纸面诊断。在输出设置不变的纯性能候选中，任何TIFF或来源证据变化都必须拒绝，重新做画质验收。

## 旧拼接路径原生质量证据

v62/v63的成片与v60逐字节一致，改动只补充真实质量证据和验收入口。覆盖范围是兰亭使用的Planar流式singleton source scan，不能据此宣称所有legacy/PSD/投影路径都已接齐。

- 最终owner直接读取原生磁盘瓦片；缺文件、长度错误或覆盖像素无owner时明确拒绝，不从2048预览反推。发布取景的crop/world origin保留独立坐标。
- 每个来源保留实际H、局部位移、采样原点/比例及半像素降采样中心。直接源参考采用相同三次采样核；原生Jacobian仍在原始来源坐标计算。
- 清晰度观测使用原有五探针/32px窗口、归一化与shortfall阈值，64px公共观测网格限制成本。候选只属于owner的真实Capture_Station：跨机位图像不是焦点runner-up；单候选置信度仍为0。跨机位边界另用真实非sequence-bridge来源关系，不虚构闭环。
- 粗网格中心在来源外但实际owner覆盖其一部分时，在已拥有的真实像素补测；同机位各候选仍用同一探针位置/窗口。108个网格涉及118,893像素，12次受限来源重载后未解析归零；缺来源、逆映射失败保持技术失败。`candidate_measurement_count`是粗网格观测量，补测量由adaptive计数字段单列；完整窗口不足仍按原CellSamplingPlan规则返回0分，不填高置信度。
