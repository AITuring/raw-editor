# 焦点堆栈通用回归契约

阆苑女仙是一个真实的验收样本，但不能成为算法的隐含输入格式。回归测试必须能够把
输入文件改名、打乱导入顺序、拆成不同大小的焦点包，仍然只根据图像重叠和几何证据建立
机位组。参考图只允许出现在离线诊断或有明确真值的测试中，不能进入生产配准、色调或像素
合成路径。

## 不依赖文件名的测试矩阵

每个几何场景至少运行下面四种输入变体：

1. 原始顺序和原始文件名；
2. 随机打乱导入顺序；
3. 用无数字、重复数字、与拍摄次序相反的随机文件名替换路径；
4. 随机打乱顺序并替换文件名。

变体只改变路径字符串和容器顺序，不改变图像像素、EXIF 和真值变换。四种变体的机位组
数量、每组成员集合、连接关系和最终覆盖应一致。文件名可以作为候选排序的稳定 tie-break，
但不能单独创建几何边、改变组边界或填补没有图像证据的断裂。

## 必须记录的指标

一次运行输出一份机器可读诊断（JSON 或 alignment cache），并同时打印下列指标。指标按
“检测/几何/融合/资源”四类保存，禁止只输出一个成功布尔值。

### 检测和机位分组

- `source_count`：输入源图数量；`accepted_source_count`：进入最终画布的数量；
- `capture_group_count`、`capture_group_sizes`：自动识别的机位组及大小；
- `group_membership_stability`：四种输入变体中成员集合完全相同的比例；
- `group_motion_drift_px`：组内投影中心相对锚点的中位数和最大值；
- `unresolved_source_count`：没有可靠重叠或被拒绝的源图。除非用户显式选择允许不完整输出，
  长扫描中该值必须为零。

### 几何和闭环

- `verified_edge_count / candidate_edge_count`：有实际点或局部像素证据的边比例；
- `connected_group_count / capture_group_count`：机位级图是否连通；
- `median_overlap_fraction` 和 `minimum_overlap_fraction`：相邻机位的真实重叠；
- `median_symmetric_error_px`、`p95_symmetric_error_px`：边的对称重投影误差；
- `loop_closure_residual_px`：非树边在联合优化后的闭环残差；
- `rejected_bridge_count`：因空间支持不足、尺度不符或残差过大而拒绝的桥接边。

树可以作为初值，但验收必须使用所有可靠的水平、垂直和跨列闭环。若机位图不连通、有效
重叠不足或闭环残差超限，应返回可解释的失败，而不是生成一张貌似完整的图。

### 清晰度、覆盖和接缝

- `source_ownership_coverage`：输出有效像素中可追溯到真实输入源的比例；生产路径不得用
  生成纹理把缺失来源计入该指标；
- `sharpness_gain_vs_single_source`：抽样笔画/边缘区域相对最佳单张源图的梯度或 acutance
  提升；应按区域记录，不能用全图平均掩盖失焦块；
- `ownership_switch_on_high_gradient`：高梯度处接缝穿过笔画的比例；
- `ghost_edge_rate`：在重叠区检测到双边缘或重复笔画的比例；
- `tone_step_p95`：低频色调校正后跨接缝的 95 分位阶差。

验收图像时，`source_ownership_coverage` 是硬门槛；清晰度、双边缘和接缝指标需要结合
局部诊断图查看。低纹理纸面没有足够梯度时应标记为 `unknown`，不能伪造“处处清晰”。

### 效率和资源

- `prepare_ms`、`match_ms`、`group_solve_ms`、`tile_fuse_ms`、`render_ms` 和总耗时；
- `pair_candidates`、`verified_pairs`、`virtual_tile_count`；
- 峰值 RSS 或分配高水位，以及最大同时解码源图数；
- `source_pixels_per_second` 和 `output_pixels_per_second`。

效率比较必须在同一机器、同一输入和同一输出尺寸下进行。报告原始逐图路径与机位内
virtual tile 路径的阶段耗时；不要把只生成缩略图的预览时间当作完整输出速度。大于有界
阈值的堆栈应使用邻近候选/视觉检索，不能退化成全成对匹配。

## 泛化回归场景

常规自动回归至少包含以下合成或本地授权素材：

- 同焦段蛇形扫描：横向、纵向和方向交替，导入顺序与拍摄顺序分别打乱；
- 每个机位含 2、4、8、16 张不同焦点图层，包含一层低纹理或明显失焦图；
- 轻微手持旋转/缩放和不超过平面假设的小残差；
- 两个焦段的连续扫描，包含可验证的跨焦段桥和没有重叠的错误桥候选；
- 低纹理纸面、重复印章/题字、曝光和白平衡缓慢变化；
- 一张断裂图、重复图和移动物体，用于确认拒绝或标记不确定，而不是静默拼入。

每个场景应有一个不含用户文件名的场景 ID。测试代码以 `id`、合成真值变换或图像内容
建立预期，不得匹配 `DSC_3743`、`3747` 等具体路径。真实 84 张 NEF 只作为额外本地验收，
不能是唯一通过条件。

## 建议的通过条件

对于有完整重叠真值的合成场景：四种输入变体的组成员集合和输出覆盖完全一致，所有有效
源图都被保留，机位级闭环和像素重投影误差低于场景阈值，且没有双边缘区域。

对于没有逐像素真值的真实素材：必须记录输入变体稳定性、连通性、重叠和来源覆盖，并把
清晰度/接缝结果交给固定 ROI 的人工或离线图像检查。报告应区分 `passed`、`diagnostic-only`
和 `rejected`，不能把一次成功渲染等同于算法普适性。

当前建议先把 4–8 张单机位包作为快速回归，再扩大到 12–16 张、多机位 tile，最后运行完整
84 张素材。只有在文件名替换和导入顺序打乱后指标仍稳定，才能把阆苑女仙结果视为通用算法
的回归证据。
