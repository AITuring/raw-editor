# 书画任务卡与诊断卡

当前任务及勾选只在 [tasks.md](../../.kiro/specs/layered-camera-group-focus-stitching/tasks.md) 维护；本目录记录执行过程、证据和复看材料，不另排一份开发任务表。已有记录：[任务1](1-resource-freeze.md)、[任务2](2-run-matrix.md)、[任务3模板验收](3-templates.md)、[任务4两槽演练](4-two-slots.md)、[任务6兰亭纸面接缝](6-paper-seams.md)、[任务7置换检验](7-permutation.md)、[任务8 provider审计](8-provider-audit.md)、[任务9来源锁定设计](9-source-lock-design.md)；任务5按各`S2-*`诊断卡记录。用户待看事项统一登记到 [复看队列](review-queue.md)。

## 使用规则

- 一项任务一张 lane 卡，命名为`<任务号>-<主题>.md`；全量摸底按任务5约定使用`S2-<dataset>.md`，一套输入一张诊断卡，可直接采用下方诊断模板。重跑在原卡追加有版本的记录，不覆盖旧失败。
- 开工前从tasks.md核对依赖、修改区域和冲突；代码任务使用独立worktree。资源槽、共享编译目录、冻结和运行方法见 [stack-lab说明](../../scripts/stack-lab/README.md)。只读分析、文档整理不占槽，也不能据此启动编译或素材运行。
- 每个实际运行绑定输入范围、命令、冻结二进制、原始报告和输出摘要。仓库内证据用相对链接；本机图片、原始素材和输出记录绝对路径及SHA，不把原图复制进仓库。
- 数值来自报告、日志或明确的计算。`0`只表示实际测得零；缺字段写`unavailable`并说明原因，未运行写`not_run`，内容不适用保留`not_applicable`。不能把未知状态补成通过。
- 每项结论写明全量/子集、scale及版本。scale=0.25的TIFF不算原生D2；文件存在不算QG通过，QG通过不算用户确认。D1–D5以 [tasks.md §3](../../.kiro/specs/layered-camera-group-focus-stitching/tasks.md#3-改进计划) 为准。
- 只由L0更新当前任务勾选和总进度。任务卡中的执行状态不是另一份验收勾选；D4须绑定用户原话、确认日期、输入范围和成片版本，D5还须同一冻结二进制两次独立运行一致、资源合规和保护冻结。

## 新素材接入步骤

以下流程不改变tasks.md的批次与依赖；先满足当前阶段的前置任务，再启动真实运行。

1. **登记范围**：确定一幅画的文件夹、拍摄批次、原始输入和派生参考；按 [fixture约定](../../tests/acceptance/README.md) 登记 [数据manifest](../../tests/acceptance/focus-stack-datasets.json)。记录数量、扩展名、排除及排序、字节/SHA和参考用途。原素材与参考只读，参考不得成为生产像素或配准关系证据；暂缓的马远PSD不加入当前矩阵。
2. **建立卡片与版本**：新素材按tasks.md任务17登记，再建立`S2-<dataset>.md`；旧素材摸底对应任务5。记录v1、冻结label和SHA。只做诊断的任务不改算法。运行新label和独立输出目录，不沿用旧结果冒充本次运行。
3. **检查入口**：在build槽运行dataset合同检查（需要实图时加`--require-data`），确认清单；涉及准备/解码/坐标行为变化时按fixture说明加`--hash-inputs`。所有编译/Rust测试用build槽和共享target，运行只用冻结副本。
4. **排资源并摸底**：任务5用`base-2026-11-12`、scale=0.25。未知峰值、首次84/98/126张、预估>20GiB和性能计时必须exclusive；实际门为24GiB。空闲<40GiB或任务输出≥20GiB时停止新运行。调用方式见stack-lab说明，不为满足预期调阈值。
5. **完成D1诊断**：来源逐项参与或明确排除，记录实际路径、机位、停止阶段、完整失败链、资源、预览和问题坐标；即使失败也交诊断卡，字段缺失列作后续观测缺口。L0据证据归组，决定任务7/8/15是否前置。
6. **逐级推进**：D2要求scale=1原生RGBA16 TIFF与来源合同；D3还要求QG及闭环通过或明确不适用。依次保留失败和通过证据，必要时使用矩阵的独占重跑。达到D3后准备整图和关键1:1裁片，按复看队列入队；没有参考的素材同样需要用户确认。
7. **交付与冻结**：用户明确确认本输入和版本才记D4；D5须同一冻结二进制两次独立输出摘要一致、RSS≤24GiB且回归保护冻结。由L0按当前任务规则将新D5素材加入全量层，中等层保持有界，再更新任务及总进度。
