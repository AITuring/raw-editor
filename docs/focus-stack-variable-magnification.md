# 跨机位倍率变化：几何采样与验收方案（v34，2026-11-04）

> [返回项目进度与任务总览](project-progress.md#n4) · 专项文档。本文维护几何采样、倍率、覆盖和参考注册的专项设计及v34/v35证据；各版本“下一阶段”仅代表当时结论，当前任务以总览为准。

## 目标与边界

按本轮授权，将真实成像倍率与配准误差分开。v33 已证明阆苑、文苑的约 0.91 / 1.12 倍关系来自原生对应点，不能靠改 anchor、owner 或坐标单位消除。本轮只增加跨机位几何契约，保留 9 张 NEF 正对照、所有未提交修改与既有 Quality Gate。连接成功不等于画质验收成功。

## G0：固定证据与坐标契约

- 开始前保存工作区文件哈希、差异、v32 Rust 源码清单；新结果写独立 v34 目录，历史报告和 TIFF 不覆盖。
- Source_RAW 原生校准坐标 → station-local anchor → Virtual Tile 裁切坐标 → station world → output lattice。各矩阵方向、裁切原点、金字塔半像素映射不变。
- 保留当前 `anchor=identity` 和原生 station 平面；不按估计倍率预缩放平面，也不将尺度归一成 1 来绕过验收。RAW seed 仍只提供初值，权威匹配来自已覆盖的 Virtual Tile 像素。

## G1：有界倍率关系（新几何契约）

| 判据 | v34 行为 |
| --- | --- |
| 旧关系尺度 `[0.95,1.05]` | 完整保留兼容路径，不增加排序或像素变化 |
| 超出旧范围的关系 | 仅原生 Virtual Tile 可以申请 `bounded_native_magnification_v1`，Source_RAW 共识路径不自动放宽 |
| 倍率包络 | 原生关系面积尺度 `sqrt(det J)` 在 `[0.8,1.25]`，正反向对称。是第一阶段有界支持范围，不宣称任意变焦支持 |
| 空间交叉验证 | 在原生 source 网格按棋盘格分开 fit/test；两侧各 ≥24 对；留出点双向误差中位数 ≤3px，凸包/真实 covered overlap ≥20% |
| 多区域稳定性 | 留出点包围盒四区域各 ≥6 对，各区域双向误差中位数 ≤3px |
| 尺度重复性 | refit 与候选模型在 9×9 原生网格上尺度相对偏差 ≤1%；两者必须保持正 Jacobian |
| 局部形变 | 9×9 网格含边界，候选面积尺度 max/min ≤1.10；Jacobian 最大/最小奇异值 ≤1.10。仍保留最终站点 Local_Scale 约束 |
| 其他几何门禁 | ≥24 内点、误差 ≤3px、support ≥20%、非凸/翻折拒绝、闭环 median≤2px/P95≤3px、修复位移边界全部不变 |
| 光度与结构 | 低频差≤20%、边缘强度 `[0.7,1.4]`、方向≤10°与已有独立样本光度补偿规则不变 |

1.25 的倍率上限是明确的产品支持边界（反向为 0.8），不是从素材名称分支；更大倍率暂时拒绝。空间留出使用当前匹配集合，不宣称它是全新采集或全流程无选择偏差的数据。候选仍须通过独立的密集像素验证。9×9 网格是采样检查，不宣称连续全像素证明；最终站点 guard 与 Quality Gate 继续生效。

所有新增证据必须在假设选择、修复聚类和最终 solver 使用同一计算函数；最终 solver 从实际 native 对应点重新计算，禁止仅信任诊断或 seed。新增 `scale_evidence` 记录版本、fit/test 数、留出误差/support、四区域数/误差、尺度包络/变化/各向异性/重复性和是否通过。失败保留原 `station_relation_scale_out_of_range`，具体原因从证据字段定位。旧范围关系字段省略，保证报告兼容。

保持 source path/hash、RAW decode 与 source cache 统计、fusion owner legend、source refinements、station owner evidence、Coverage_Mask、ROI 路径与不可测原因。不得通过 owner 替换掩盖倍率变化。

### 文苑联合几何

根因有两处：矩阵闭环在联合原生优化前删除0–2关系，随后联合优化因关系数小于机位数而跳过；联合分解又把统一输出密度计入camera corner movement，使几何修正的256px预算被整体缩放消耗。

修复在有原生倍率证据的VirtualTile图首次准备剪边时，先以全部已通过局部门禁的关系执行联合优化。成功仍需通过既有留出误差、每对P95≤3px、全局median≤2px、局部变化、方向和corner门禁；失败返回原剪边/拒绝路径。`closure.native_joint_before_prune`记录关系数、原矩阵P95及是否接受。旧范围图不进入新分支。几何分解仅纠正camera/field，输出密度仍由完整SourceSamplingMap Jacobian规划，不能降低密度来通过闭环。

最终真实10张保留3条关系，closure=converged，原生每对最大P95从v34的16.233545降至1.810738px、median=0.784977px、最大corner movement=15.277303px。density=1.1796875，换算输出格分别为2.136105px、0.926028px、18.022443px。9764×9827 RGBA16 sRGB TIFF已通过原生验收，QG pass /8 ROI /8 station owner evidence；MTF等内容不适用状态按既有规则保留。

初始几何候选曾因旧矩形覆盖97.3072%被拒绝，其记录仍在`cross-station-v35-geometry-coverage`。最终TIFF与该几何候选逐字节相同，SHA `8ce0afa00b4fce60701f7aec506421279424fe0c24e554cebc16e45868194e7b`；后续变化是覆盖测量修正，没有修改输出像素以通过门禁。

### 独立物理来源域与98%覆盖门禁

旧分母投影校准画布的四角矩形，渲染器却按照原始传感器footprint拒绝校准padding，二者定义不一致。现在逐输出像素中心通过residual逆映射、native correction、station origin和SourceSamplingMap回查原始来源支持，取全部有效来源域的并集。分母只依赖来源几何，分子为该域与输出alpha覆盖的交集；不能用alpha、owner或亮度空洞反向缩小分母，域外不透明像素不能补偿域内缺失。

校准原生路径缺少任一必要映射或域无效时拒绝计算；纯旧采样路径保持原计算。逐行整数归约，不解码额外RAW、不分配全画布支持域位图。`effective_source_domain`保留方法、来源数、旧矩形并集、全部alpha、域内覆盖/缺失和域外不透明计数。Composition的`opaque_pixels`和`union_projected_pixels`仍保存历史全部alpha/矩形计数；QG的`effective_output_pixels`和`effective_projected_pixels`使用物理域，不能混读。逐station历史贡献统计也不是每机位独立98%覆盖指标。

| 最终真实子集 | 域内覆盖 / 独立来源域 | 覆盖率（门槛98%） | 域内缺失 | 域外不透明 | 旧矩形并集 / 全部alpha | 测量耗时 |

| 文苑10 | 90,155,203 / 90,633,376 | 99.472410% | 478,173 | 8,592 | 92,658,876 / 90,163,795 | 2.592s |
| 阆苑10 | 118,730,536 / 119,397,609 | 99.441301% | 667,073 | 10,824 | 122,171,267 / 118,741,360 | 2.554s |

历史`footprint_uncovered_nontransparent`表示4×4插值模板触及station coverage之外，并不等于像素中心位于传感器外。v34的1,784,375保留为模板诊断，不能直接扣减分母。3项定向测试覆盖alpha独立分母、真实孔洞仍失败、全黑有效来源、局部映射/非零原点，以及空/非有限域拒绝。

### 受限参考图配准
