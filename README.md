# RAW Editor

  <img src="public/logo.svg" alt="RAW Editor 标志" width="128" height="128" />
</p>

RAW Editor 是一款桌面照片编辑工具，提供 RAW 调整、局部编辑、图片管理、堆栈拼接和分区亮度校正。照片处理在本机完成，编辑参数与原始文件分开保存。

## 图片管理

- 从文件或文件夹导入照片，浏览缩略图与胶片栏。
- 使用评分、颜色标签、筛选和排序整理照片。
- 查看拍摄参数与 EXIF 信息，管理相册和虚拟副本。
- 在图库、单图预览和编辑器之间切换。

## RAW 与色彩调整

- 调整白平衡、色温、色调、曝光、对比度、高光、阴影、白色和黑色。
- 使用曲线、HSL、颜色分级与黑白调整控制影调和颜色。
- 调整纹理、清晰度、去雾、自然饱和度和饱和度。
- 提供锐化、亮度降噪、颜色降噪、暗角与颗粒效果。
- 查看直方图，通过缩放、平移和原图对比检查细节。

## 裁剪与几何校正

- 支持自由裁剪、预设比例、自定义比例和横竖比例切换。
- 支持精细旋转、90° 旋转、水平翻转、垂直翻转与画线拉直。
- 提供自动、水平、垂直、完全和引导式透视校正。
- 使用参考线辅助构图，调整画面比例、缩放和偏移。
- 支持镜头畸变及色差校正，并可选择保留变换后的空白边缘或约束裁剪范围。

## 局部编辑

- 使用画笔、线性渐变和径向渐变创建局部蒙版。
- 按颜色范围或明度范围选择需要调整的区域。
- 支持蒙版添加、减去、相交、反转、羽化和透明度调整。
- 对选定区域调整亮度、色彩与细节，使用修复和仿制工具处理局部瑕疵。

## 分区提亮与亮度可视化

从首页、图库工具栏或编辑器中的太阳图标打开「区域亮度工具」，可接入当前选中的图片，也可单独导入或拖入图片。

- **亮度分布图**：以颜色和数值展示各区域的平均亮度，帮助寻找偏暗或偏亮的位置。
- **分区调整**：通过 6×4 手动网格选区，分别提亮或压暗；区域之间采用平滑过渡。
- **自适应校正**：根据图像内容分析明暗分布，一键校正大范围亮度不均，并可调整校正强度。
- **区域保护**：指定当前区域不参与自动调整，同时保留手动调整能力。
- **纯图预览**：一键显示或隐藏亮度图层，放大、缩小和平移查看效果，随时恢复适应窗口。
- **独立导出**：复用图片堆栈的导出对话框，支持 JPG、PNG、TIFF，以及尺寸、质量和元数据设置。

从编辑器打开时使用当前可用的图片预览；需要检查原图细节时，可通过「更换图片」重新导入。工具默认导出尺寸的最长边上限为 6000 像素，可在导出对话框中调整尺寸，放大导出不会恢复预览中缺失的细节。

### 接缝诊断（实验）

沿候选接缝检查亮度变化，并结合源尺寸局部采样和同侧纹理对照提供诊断。支持逐条查看候选、开关标记和排除候选。

诊断目前仍可能漏检或将画面结构列为候选，仅提供检查线索，不会自动修复接缝。自适应亮度校正也不能代替错位、重影或裂缝修复。

## 图片堆栈与拼接

- **焦点堆栈**：合成多张不同对焦位置的照片，扩展清晰范围。
- **全景拼接**：组合有重叠区域的照片，生成更大的画面。
- 支持整理输入图片、检查合成预览、查看处理进度并导出结果。
- 合成效果取决于输入照片的重叠、对焦、曝光与几何一致性。

## 预设与批量处理

- 保存和应用调整预设，复制或同步照片的编辑设置。
- 使用撤销、重做及编辑历史比较不同调整效果。
- 对多张图片执行批量几何处理和导出。

## 参考图色彩迁移

- 从参考图片提取色彩与影调风格，应用到目标图片。
- 支持色调氛围和 RGB 分布两种匹配方式，可调整迁移强度。
- 在本机预览结果，查看色相、饱和度、亮度与对比度变化，并独立导出。

## 导出与元数据

- 按使用场景选择图片格式、输出尺寸和压缩质量。
- 设置水印、作者、版权、联系信息与图片描述。
- 控制元数据保留范围、GPS 信息及色彩配置文件嵌入。
- 输出调整后的新文件，保留原始照片。

## 本地工作流

- 照片编辑与图像处理在本机完成，无需账号或云端上传。
- 编辑记录保存在应用私有目录，便于继续调整。
- 提供中文、英文等多语言界面及快捷键操作。
